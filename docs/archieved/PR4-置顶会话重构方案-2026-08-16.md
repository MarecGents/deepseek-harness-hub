### 1.4 风险与边界

**"DOM 增强不可消除"限定为"行级 pin 按钮不可消除"**（审查核验：`sidebar.workspaces` 单 slot 被 ui-workspace 独占，会话行无可注册 seat）。置顶区替代方案逐项排除：整体替换 slot（丢 directoryFlow）、`shell.overlay`/body portal（浮层脱离列表滚动与视觉一体性）→ 采用 **slot 容器内、树兄弟节点流内注入**。

【v3.1 改述】置顶区为 **slot 容器内、树（`.list` 滚动区）外的兄弟节点**：独立滚动块（`max-height:40vh`），列表滚动时保持可见（官方 `.list` 是唯一滚动容器，树外兄弟不随其滚动）。"常驻"指其独立于列表滚动常驻可见。边界声明：对官方 slot cell 的运行时 DOM 增强（非官方 seat），仅 stable 锚点 + 防御性降级；只读参考 dsh 源码，不触碰铁律 #1。

【v3】空态语义（二轮 UI #2 拆分）：**0 会话**（无行可增强，observer 空转无异常，置顶区隐藏）与 **0 置顶**（行级按钮常驻——按钮是进入置顶的入口，必须始终执行；置顶区隐藏）两态分开处理。

## 第二部分：技术路线

### 2.1 目标架构

```
client half
  ctx.effect(installPinnedConversations(ctx: ClientContext))      ← rc.10 apply() 装配
    ├─ 数据层①：订阅 ctx.sessions.list（ids/byId/current/phase；ids = host 创建序）
    ├─ 数据层②：【v3】订阅 ctx.workspaces.list（archivedSessionIds —— 归档显示过滤数据源，
    │            归档集合不在 sessions.list，必须补订阅）
    ├─ 数据层③：pins 读写（GET/PUT /api/dsh-hub/pins，localStorage 兜底）
    ├─ 状态机（2.6）：dirty / readyBaselineLanded / missingStreak
    ├─ 表现层 A：置顶区（slot 容器内、role=tree 前，流内兄弟节点）
    ├─ 表现层 B：会话行 pin 按钮（增强 div[role=treeitem] 行）
    └─ 引擎：MutationObserver（收窄）+ debounce + sig 幂等 + 写路径 phase 门控
host half
  makePinsRoutes() → GET/PUT /api/dsh-hub/pins → $DSH_HOME/dsh-hub/pins.json（renameSync 原子写）
```

### 2.2 锚点（零 hash 定位）

| 用途 | 选择器 | 依据 |
|---|---|---|
| 侧栏 slot 容器 | `div[data-slot="sidebar.workspaces"]` | web-react scoped-slots L676 渲染器固定输出（addressable seam），`display:contents` 常驻 |
| 会话树 | 容器内 `[role="tree"]` | WorkspaceBrowser L388（分组）/ L619（flat）；**搜索态主树卸载、仅 searchTree**（L1109-1166） |
| 会话行 | `div[role="treeitem"]:not(button):not([aria-expanded])` | Rows.tsx L394（div 会话行）/ L132（分组行带 aria-expanded）/ L316（搜索行是 button） |
| 行 hover 作用域 | `[role="treeitem"]:hover` + `:focus-within` | hash-free；分组行无按钮无副作用 |
| 标题提取（豁免） | hash 单点（主）+ 结构性排除法（兜底） | 见 2.3 |

### 2.3 行→id 定位（【v3】歧义即跳过整组）

```
rowTitle(row) ──textContent（非 innerText，防 reflow）──► 预构建 normalizedTitle→ids[] 映射
  ├─ 0 个 → 跳过（分组/未知行）
  ├─ >1 个 → 歧义 → **跳过该标题整组**（不注入按钮、不置顶；绝不"位置对齐选择"——二轮 #1 闭环）
  └─ 1 个 → 命中（blank 会话由 summary.blank 守卫，另行排除）
```
- 每次 sync 预构建 `normalizedTitle → ids[]` 与 `id → 索引` 映射各一次（O(n)，P3-1）。
- **标题提取（P1-4 决策，二轮确认可接受）**：主 = hash 单点例外（`.YDXeBa_title` 等，文档化豁免，与 pin 图标特例同模式，dsh 升级回归清单 +1）；兜底 = 结构性排除法（非 status visually-hidden、非时间、非操作区文本的首个 span）；两者失败 → 跳过该行（读错 = 跳过，不误标）。
- **blank 行结构性排除（三轮 #4）**：标题匹配命中的会话若 `summary.blank === true` 一律跳过（守卫已有）；另加 DOM 级结构性排除——无 time 且无 rowActions 的行视为 blank/非会话行候选（`flatSessionRowWithoutStatus` 形态），命中即跳过，防"新会话"本地化文案与真实会话同名时误注入。

### 2.6 正确性 / 健壮性（【v3】状态机显式化）

**状态机**（二轮 #5 要求定义）：
- `dirtyDelta: { added: Set<id>, removed: Set<id> }` —— boot 窗口内用户交互的增量（新增/取消分别记录；v3.1 由 boolean dirty 升格，修复"并集合并复活被取消条目"——三轮 #1）
- `readyBaselineLanded: boolean` —— 首次 `phase==='ready'` 快照已落地（ready 单调不回退，与基线同快照，无死锁）
- `missingStreak: Map<id, number>` —— 连续 ready 快照中该 id 缺失计数

**写/读门控分离**（二轮 #5）：**写路径**（persist 收缩 / boot 覆盖 / 剪枝）门控 `readyBaselineLanded`；**渲染路径不门控**（pending 时用 LS/boot 数据渲染，byId 缺失回退 id 文本）——正常启动窗口内置顶区即可见，连接失败时不丢数据。

**boot 竞态 / 快速点击**（P1-1/M2/P2-1，v3.1 delta 合并）：boot 的 `apiGetPins().then(setPinned)` 应用 = **`(bootPinned − dirtyDelta.removed) ∪ dirtyDelta.added ∪ currentPinned`**——用户已交互的条目（含取消）不被旧列表覆盖/复活；pending 阶段写路径短路（pins.json + LS 不被空 byId 清空）；`apiPutPins` await sanitized ids 收敛。

**剪枝组合条件**（二轮 #3）：`persist(live)` 收缩仅当 `readyBaselineLanded && (missingStreak[id] >= 2 ∨ 显式取消置顶)`；**显式删除 PR 的 `syncPinnedSection` 即时 `persist(live)` 收缩路径**（live 仅用于渲染）。

**reconnect 瞬态缺口**（P2-4）：剪枝只显示不删（missingStreak 计数）；连续 2 次 ready 缺失或显式 unpin 才删。

**HMR/重装僵尸**（P1-3）：disposer 移除注入 DOM（行按钮、置顶区、marker/class）——重装即重建；`togglePin` 加 `if (!alive) return`；按钮监听同引用可替换。

**re-parent**（P2-5）：sync 幂等位置重断言（`parentNode !== tree.parentNode || nextSibling !== tree` 才移动）；搜索恢复后自愈。

**搜索态**（P2-3/P1-3）：行分类排除 button；`section.hidden = inSearch || live.length === 0`（**单表达式，二轮 #4 闭环**；`inSearch` = 树存在且全部 treeitem 为 button；**无树（rail 收起）不算搜索**——三轮 #3 措辞修正，公式本身按原样实现即满足空态意图）。

**多实例/多标签**（P2-6）：整体替换最后写者胜 = 可接受（与 config.json 同型先例，铁律 #4 默认禁并存）；`window.addEventListener('storage')` 跨标签重同步（注记：本地单 WebView2 单标签无法自触发，防御 remote-browser 多标签场景，可测性低，保留为廉价防御）。

**原子写**：`renameSync` 真原子（仅 pins-api）。

**上限收敛**：客户端 toggle 前本地 cap 200（与服务端 sanitize 一致）。

**归档会话**（P3-3，二轮 #2 闭环）：显示过滤数据源 = **`ctx.workspaces.list` 的 `archivedSessionIds`**（补订阅）；置顶区隐藏归档条目（可恢复，不删 pin）。

**rail（折叠）态**（二轮 #7）：`!wide` 时树不渲染 → `findTree()` 为 null → 置顶区不渲染；展开后 observer 自愈（re-parent）。文档化，验收不困惑。

**空态**：0 会话 observer 空转无异常；0 置顶行按钮常驻（首个 pin 可点）。

**性能**：预构建映射 + textContent + observer 收窄 + 250ms debounce（首次锚点发现即时注入，P2-1 UI）。
