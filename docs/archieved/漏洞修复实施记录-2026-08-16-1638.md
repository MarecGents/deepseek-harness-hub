### C 组（进程/身份）
- **C1 hub-exe 缓存自指 + 每启重建**：cacheKey → `${process.versions.node}|${process.arch}|${VERSION}`（去掉 exe stat——guard 运行时 execPath 是补丁副本，stat 永远不匹配）；launcher main() 在 re-exec 前 `await ensureHubBinaries()`（try/catch 保留回退），node 升级后的重建发生在真 node 进程上，避免 EBUSY。
- **C2 guard spawn 失败静默退出**：`relaunchAsGuard` 返回 `Promise<boolean>`，`once('spawn')` 才 resolve(true)，`once('error')` resolve(false)（回退 plain-node 路径）；launcher `await`。
- **C3 单实例锁 TOCTOU**：`writeFileSync(file, data, { encoding:'utf8', flag:'wx' })` 原子独占创建（3 参对象形式——4 参位置参数形式会静默丢 flag，实测 Node 24/Windows 复现）；EEXIST → 读 pid 判存活；死/空 owner → 删除重取，重取再冲突则再判存活。矩阵验证：同进程自身持有→拒绝；释放→可获；空文件→接管；死 pid→接管；跨进程持有→拒绝。
- **C4 多实例检测只匹配 node.exe**：CIM 过滤 `Name='node.exe' -or Name='dsh-hub.exe' -or Name='dsh-hub-guard.exe'`（CommandLine 仍匹配 dsh.*web；guard 自身命令行不含 web，不会自匹配）。
