## 诊断（测试机 dsh.log）

- 卡占位页根因：`Cannot find package '@deepseek-ai/dsh-settings' imported from
  $INSTDIR\_up_\lib\index.js` → dsh web 启动即崩 → 3 次重启后放弃。
- `_up_` 只含插件自身文件、无 node_modules；host 侧运行时 import（dsh-settings、
  schemastery）在 `$INSTDIR` 树上无处解析（旧 registry 布局靠 npm 拉依赖、dev 态靠
  仓库 node_modules——两条路在 `_up_` 都不存在）。
- 卸载残留：Tauri NSIS 模板只跟踪主二进制；glob resources（_up_/icons）与安装期
  下载的私有运行时（dsh-hub-win，~400MB）不在卸载清单。

## 修复

1. resources 增 10 包依赖闭包（BFS deps+peers；1.8MB）→ `_up_\node_modules\`。
2. build-installer.mjs **host 依赖打包守卫**：lib host 产物外部 import 必须被闭包
   覆盖否则构建 FAIL（防复发；本次冒烟 PASS）。
3. installer-hooks.nsi `NSIS_HOOK_POSTUNINSTALL`：递归删已知子目录 + 引导日志 +
   非递归 RMDir $INSTDIR；best-effort 清 profile（bundles 条目 + 悬空 junction，
   ReparsePoint 判定——Test-Path 对悬空链接会误判 false）。
