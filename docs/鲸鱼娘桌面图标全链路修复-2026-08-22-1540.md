## 背景

上一会话（dsh-hub开发上下文）移植 PR #25 鲸鱼娘桌面图标后，用户 4 次报告切换无效；
上次以 .lnk/AUMID/SHChangeNotify 更新 + NSIS 重打包收尾（77e5081），等待用户装包
验证。本次会话接续，实测仍有多处断链。

## 根因（4 处独立缺陷叠加）

1. **ICON_BIG 从未设置**：Windows 任务栏按钮图标走 ICON_BIG 槽（tao 源码
   `set_taskbar_icon` 语义），Tauri 2 `set_icon` 只设 ICON_SMALL → 任务栏回退窗口
   类图标（exe 内嵌鲸鱼）。Alt-Tab（SMALL）变了、任务栏不变的现象完全吻合。
2. **.ico 资产是 4bpp/16 色劣质品**：上次用 PowerShell `GetHicon()+Icon.Save()`
   生成，256×256 彩色插画抖动失真、无 Alpha；任务栏 24px 下视觉近似"没变化"。
3. **`desktop_icon_ico_path` 双重前缀 bug**：`format!("whale-girl-{}", icon_id)`
   而 icon_id 已含前缀 → `whale-girl-whale-girl-sad.ico` 不存在 → 鲸鱼娘的
   .lnk/AUMID 更新从未成功（'default'→whale.ico 碰巧正确）。
4. **桌面路径近似失效**：`update_shell_icon_sources` 用 `USERPROFILE\Desktop`，
   本机桌面实际重定向在 `D:\快速访问\桌面`（FOLDERID_Desktop）→ 桌面快捷方式
   从未被更新。另发现 `create_toast_shortcuts` 先 Save 后 SetValue，AUMID 属性
   从未落盘。
