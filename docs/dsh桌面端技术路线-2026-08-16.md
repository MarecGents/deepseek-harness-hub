# dsh-hub 桌面端技术路线（Tauri 2.x 迁移）

> 版本：2026-08-16 · 分支：`dev-v2`（当前开发分支）
> 前置：`0.0.1-rc.13` 为 WebView2 壳最后一个 rc，`dev-v1` 已冻结。

## 1. 现状（WebView2 壳）

- 壳层：`dsh-hub.exe`（Node + WebView2），Windows 专属。
- 渲染：WebView2（Chromium）承载 web UI（`src/client` 全部前端）。
- 桥接：host（Node）↔ webview 的 `webviewjs` 协议；`desktop.ts` + `services/`（dwm-theme、tray、theme-sync、launcher 单实例锁）。
- 运行时：依赖系统 WebView2 Runtime，安装包体积大、仅 Windows。

## 2. 目标（Tauri 2.x 壳）

- 三端支持：Windows / macOS / Linux。
- 体积：~10MB 级（Rust 壳 + 系统 WebView 渲染）。
- 自定义壳 UI：无边框 + 透明窗口 + 背景图穿透（延续 rc.13 视觉体系）。

## 3. 分层架构（迁移不变式）

```
┌─────────────────────────────────────────────┐
│  shell 层（重写为 Rust）                       │
│  main.rs / lib.rs：窗口管理、托盘、单实例、    │
│  主题同步、launcher lock、workspace 路径      │
├─────────────────────────────────────────────┤
│  桥接层（重写）                                │
│  webviewjs 协议 → Tauri IPC（invoke/event）   │
├─────────────────────────────────────────────┤
│  插件层（原样保留，零改动）                     │
│  Cordis 插件 + src/client UI +                │
│  config/workspace API                         │
└─────────────────────────────────────────────┘
```

- **壳层**：`desktop.ts`、`services/*`、`bin/*` 逐一映射为 Rust 实现（见 §4 映射表）。
- **插件层**：client UI（背景图/皮肤/右侧栏/设置卡片）、config/workspace API、Cordis 装配机制不变——webview 内运行，与壳解耦。
- **Node 运行时**：Cordis 插件层仍是 Node 生态，Tauri 壳以 **sidecar**（tauri-plugin-shell 拉起 node 进程）或内嵌运行时承载；webview ↔ node 的既有桥语义不变，仅传输层替换为 Tauri IPC。

## 4. API 映射表

| WebView2 壳（现状） | Tauri 2.x（目标） |
|---|---|
| `BrowserWindowOptions.logical` 尺寸/位置 | `WebviewWindowBuilder` + 逻辑像素换算 |
| `setSize / setMinSize(w,h,logical?)` | `window.set_size / set_min_size`（物理像素，需换算） |
| 无边框 + 透明窗口 | `decorations(false)` + `transparent(true)` |
| dwm-theme 服务（Windows） | `window-vibrancy` / `window-effects`（Win/macOS） |
| tray 服务 | `tauri-plugin-tray`（tray-icon） |
| theme-sync 服务 | `tauri-plugin-window-state` + `Theme` 事件 |
| launcher 单实例锁 | `tauri-plugin-single-instance` |
| workspace 路径 / 文件 API | `tauri-plugin-fs` / `app.path()` |

## 5. 迁移里程碑

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1 脚手架 | `src-tauri` 初始化，最小无边框透明窗口 | 窗口可显隐，无崩溃 |
| M2 窗口管理 | 尺寸/位置/最小尺寸/主题与 rc.13 行为对齐 | 行为一致（含逻辑像素换算） |
| M3 系统服务 | 托盘、单实例、launcher lock、dwm 主题 | Windows 上与 rc.13 等效 |
| M4 插件层接入 | node sidecar 装配 Cordis，config/workspace API 打通 | 插件层零改动运行 |
| M5 三端发布 | macOS/Linux 适配 + GitHub Actions 打包 | 三端产物 + 自动发布 |

## 6. 风险与对策

- **渲染引擎差异**：Tauri 在 Windows 上仍是 WebView2（背景合成问题理论一致）；Linux 用 webkit2gtk、macOS 用 WKWebView，`position:fixed` 合成行为可能不同 → M1/M2 逐端做透明背景像素验证。
- **Node sidecar 分发**：三端需捆绑对应 Node 运行时 → 打包脚本按平台下载固定 Node 版本（volta pin）。
- **IPC 语义替换**：webviewjs 回调模型 vs Tauri event/command 模型差异 → 桥接层做薄适配层，插件层不感知。

## 7. 最终验收标准

- 与 rc.13 视觉一致：背景图透明度（左/右栏 10%、中栏 25%）、皮肤体系、右侧栏样式。
- 插件层（client + config/workspace API）零改动运行。
- 三端发布产物可用，安装包 ~10MB 级。
