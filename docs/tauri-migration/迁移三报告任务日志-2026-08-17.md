## 关键决策（三轮审查收敛）
1. **桥接选型**：主桥 = HTTP/SSE/WS（Node sidecar webserver 伺服，落地 T4.9）；Tauri IPC 仅壳级本地窗口命令；sidecar↔壳 stdio JSON-RPC（方向：stdout 上行请求/事件、stdin 仅 quit）
2. **多实例检测**（A1 阻断修复）：进程枚举（进程名+命令行）+ 端口探活双通道，保留 `--port 0` 随机端口语义与铁律 4 默认拒共存
3. **$DSH_HOME**：保留 rc.14 语义 `DSH_HOME env || ~/.dsh`；卸载默认保留 profiles/sessions；dsh.log → `$DSH_HOME/dsh-hub/logs/`
4. **Node 承载**：A 方案（壳+全局 npm dsh）先行 → B 方案（externalBin 内置 node，spacedrive 范式）后续
5. **安全**：capabilities 显式最小集（去 core:default 全家桶）、桥 token 会话级生命周期 + WS/SSE Origin 强制、stdio 帧标识 + READY 先验证再导航、卸载清 junction/bundles 防裸 dsh web 失败
6. **版本/口径**：Cargo 恒 0.0.0 + tauri.conf.json 引用 package.json（surrealist 式）；壳 ~10MB / 安装包 40-80MB 双口径

## 最终结论（审查轮 3）
三角度全部**可验收**：架构无遗留阻塞、风险安全附条件（P4/P5 动工前核实 + 决策点拍板 + verify-tauri-release 门禁）、兼容运维 2 项必补已在本轮闭合。达到**可无缝迁移落地**标准，可进入 M1 里程碑（src-tauri 脚手架 + 最小无边框窗口）。
