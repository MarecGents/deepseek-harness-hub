# 标题栏按钮失效 — DMAIC 调研与修复记录

> 日期：2026-08-17 · 问题：Tauri 壳自绘标题栏最小化/最大化/关闭按钮点击无反应

## Define（定义）

- CTQ：标题栏按钮（─/□/✕）点击后窗口执行对应操作（minimize/maximize/close）
- 缺陷：点击无任何反应（invoke 被静默拒绝）

## Measure / Analyze（测量与分析）— 根因链（官方源码证据）

1. **`__TAURI_INTERNALS__` 注入所有 webview**（含 External URL）
   - 证据：`tauri-2.11.5/src/app.rs` `InvokeInitializationScript` 模板注入

2. **`is_local_url()` 判定 external URL = Remote origin**
   - 证据：`tauri-2.11.5/src/webview/mod.rs:1698`：非 tauri://、不相对 devUrl/frontendDist → remote
   - 我们的页面 `http://127.0.0.1:<随机端口>` ≠ devUrl `http://127.0.0.1:17891` → **Remote**

3. **remote origin 触发 app 命令 ACL 强制检查**
   - 证据：`tauri-2.11.5/src/webview/mod.rs:1823`：
     ```rust
     if (plugin_command.is_some() || has_app_acl_manifest || !is_local) && ... && invoke.acl.is_none()
     ```
   - `!is_local`（remote）→ 强制 ACL → `invoke.acl` 来自 `resolve_access`（capability 匹配）→ capability 无 app 命令权限 → `acl.is_none()` → **reject**

4. **M1-M3 为什么能工作**：devUrl 页面（17891）相对 devUrl → `is_local=true` → 跳过 ACL → app 命令（ping）天然放行

## Improve（改进）— 修复方案（已实施）

1. `src-tauri/build.rs`：`tauri_build::try_build(Attributes::new().app_manifest(AppManifest::new().commands(&[...])))`
   - 自动生成 `allow-$command` / `deny-$command` 权限（`tauri-build-2.6.3/src/acl.rs:55-57`）
2. `src-tauri/capabilities/default.json`：permissions 加 `allow-*` 条目 + `remote: {"urls": ["http://127.0.0.1:*"]}`
3. **closeToTray 额外修复**：`win.listen("tauri://close-requested")`（Rust 侧）不满足 `has_js_listener` 检查（`manager/window.rs:172` 只在 JS 侧有 listener 时 prevent_close）→ 窗口真正关闭退出进程。改用 `win.on_window_event(CloseRequested { api, .. })` + `api.prevent_close()` + `hide()`
4. 新增 `diag_report` 命令（远程页 invoke 链路诊断用）
