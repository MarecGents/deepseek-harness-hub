# 壳功能四改进（托盘/主题跟随/提示音弹窗/托盘菜单美化）— DMAIC 记录

> 日期：2026-08-18 · 范围：Tauri 2.x 壳（设置→插件→DSH HUB 设置 对应能力）
> 用户需求：① 最小化/关闭到托盘 ② 标题栏颜色跟随皮肤主题（快速无感）
> ③ 提示音与弹窗（弹窗必须清晰可用）④ 右下角托盘菜单美化（布局/尺寸/字体色/背景色跟随皮肤）

## Define（定义）— CTQ 与验收标准

| # | CTQ | 验收标准（可测量） |
|---|---|---|
| ① | 最小化到托盘 | 点标题栏 ─ → 窗口隐藏（任务栏消失、进程存活）；托盘左键恢复窗口 |
| ① | 关闭到托盘 | 点标题栏 ✕ → 窗口隐藏（进程存活），不退出；closeToTray=false 时退出 |
| ② | 标题栏皮肤跟随 | 浅色皮肤（body 无 dark 标记）→ 深色标题栏；深色皮肤 → 浅色标题栏；切换 ≤0.2s 平滑（transition 实测） |
| ③ | 任务完成弹窗 | 任务完成 → 系统 toast 弹出（`notify: toast sent` 日志 + 真机可见） |
| ③ | 提示音 | HTMLAudio 播放（D3 决策；远端无法听声，链路代码级验证） |
| ④ | 托盘菜单美化 | 右键托盘 → 自绘菜单浮层（右下角、200px、4 项、圆角/阴影/悬停态）；背景/文字/边框随皮肤双块切换；点击项行为正确 |

## Measure / Analyze（测量与分析）— 调研结论（自研，源码证据）

1. **最小化事件缺失**：Tauri 2 无独立 `Minimized` 窗口事件 → 用 `WindowEvent::Resized` + `win.is_minimized()` 检测（官方 issue 共识做法）。
2. **关闭拦截**：`win.listen("tauri://close-requested")`（Rust 侧）不满足 `has_js_listener`（manager/window.rs:172）→ 必须 `on_window_event(CloseRequested{api})` + `api.prevent_close()`（上轮 DMAIC 已修）。
3. **皮肤机制**：dsh 皮肤 = `body`（浅）/ `body[data-ds-dark-theme]`（深）双块 CSS；`data-ds-dark-theme` 由 dsh 主题设置驱动（skins.ts buildCss 同选择器）。标题栏 CSS 用同一属性做「反色 chrome」（浅皮肤→深栏，深皮肤→浅栏）。
4. **原生托盘菜单不可美化**：Tauri `MenuItem/Menu` 是平台原生菜单（系统绘制），字体/颜色/布局不可自定义 → 自绘 HTML 浮层是唯一路径。
5. **通知链断点**：`tauri-plugin-notification` 在 Cargo.toml 但 **Builder 未注册** `tauri_plugin_notification::init()` → `app.notification()` 无插件状态 → 弹窗静默/panic。通知链：client（index.ts notifyTaskComplete）→ tauri-shell.ts `invoke`（stdout DSH_CMD）→ node.rs dispatch → `notify_task_complete` 命令 → 插件 toast。
6. **初始化脚本时序（新坑）**：Tauri `initialization_script` 在**文档创建时**执行（HTML 未解析，`document.head/body` 为 null）；解析期 DOM 访问抛错会杀死整个脚本（标题栏/菜单全失效）。必须把 DOM 操作推迟到 `DOMContentLoaded`（initShell）。
7. **装配双挂（新坑）**：`assemble-profile.mjs` 步骤 5 复制包内 `cordis.patch.yml`（含 `insert: id: dsh-hub`）到 profile，同时步骤 2 注册 bundles → 同一插件双装载路径 → 全新 profile 首启即崩 `duplicate loader entry id: dsh-hub`（launcher.ensureBundleInstalled 从不复制 patch，bundles 是唯一装载机制）。
8. **恢复最小化窗口**：最小化→隐藏后，托盘恢复需 `unminimize()` + `show()`，否则 ShowWindow 只把最小化窗口显示到任务栏。
9. **事件系统在 remote origin 不可用（D-2 实测，本任务最大发现）**：`window.__TAURI_INTERNALS__` **只注入 `invoke`/`transformCallback`/`runCallback`/`plugins`，没有 `.event` 对象**（事件 API 在 `@tauri-apps/api` 包里，页面不打包它）。实测三方向全失效：Rust `app.emit` → 页面 `event.listen`、页面 `event.emit` → Rust `app.listen`、页面自送达。**invoke（命令）与 win.eval 是仅有的两个可靠通道**。壳桥重设计：页面→Rust = invoke 命令（`tray_quit`/`open_workspace_path`，ACL allow-*）；Rust→页面 = `win.eval`（`__mgTrayMenuToggle`）；同页交互 = CustomEvent（client 已监听）。
