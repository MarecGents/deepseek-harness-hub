## 1. 概述

### 1.1 落地原则

1. **每阶段可运行**：M1–M5 每个里程碑结束都必须有一个可启动的产物（`cargo tauri dev` 或打包安装包），不允许出现"只写了一堆代码但跑不起来"的中间态。
2. **每阶段可回退**：所有 Rust 代码集中在新增的 `src-tauri/` 目录，不修改任何现有插件层文件（`src/client/*`、`src/services/config-api|workspace-api|pins-api|backgrounds-api`、`cordis.patch.yml`）；每个里程碑一个独立提交，回退 = `git revert` 单点。`dev-v1` 冻结不动，rc.14 随时可安装兜底（依据：根 AGENTS.md §5.1）。
3. **与 rc.14 行为对齐**：窗口/托盘/主题/单实例/通知/崩溃重启等每个行为都有一行「rc.14 现状 → Tauri 目标 → 验收方法」对照（见 §9 验收总表）。行为差异（如单实例二次启动从"弹窗拒绝"改为"聚焦已有窗口"）必须在计划中显式列为**有意的行为变更**并获用户确认。
4. **插件层零改动**：React client UI、config/workspace/pins/backgrounds API、Cordis 装配机制原样保留；壳层（desktop.ts + Windows 专属 services + bin 启动器）整体重写为 Rust + 桥接适配（依据：根 AGENTS.md §1 隔离边界、§6 技术路线；docs/dsh桌面端技术路线-2026-08-16.md §3 分层不变式）。
5. **不碰 dsh 底层源码**：Tauri 壳以 sidecar 拉起 `dsh web`（官方 CLI），一切仍走官方插件接口（依据：根 AGENTS.md 铁律 1）。

## 3. M2 窗口管理迁移

### 3.1 目标

把 `src/desktop.ts` 的窗口逻辑（尺寸/最小尺寸/居中/最大化恢复/逻辑像素换算/主题/窗口记忆）逐项移植到 Rust，行为与 rc.14 一致。

### 3.2 当前行为基线（已核实，src/desktop.ts + src/services/state-store.ts）

- 启动尺寸：持久化尺寸（逻辑）> 无则 3/4 当前屏（物理，`resolveLaunchScreen` 多屏感知），兜底 1280×720；`restoreSize()` 带 `logical` 标记（desktop.ts L247-251）。
- 最小尺寸：`setMinSize(480, 360, logical=true)`（desktop.ts L335；MIN_WIDTH/MIN_HEIGHT 常量 state-store.ts L12-13）。
- 创建后 `center()`；`state.maximized===true` 则 `setMaximized(true)`（L336-337）。
- **只持久化 maximized 标志**，不存几何（L394：`Persist only the maximized flag (geometry is intentionally not kept)`）；持久化文件 `$DSH_HOME/dsh-hub-window-state.json`（state-store.ts L40）。
- un-maximize 恢复：`pendingCustomSize ?? restoreSize()` 再 `center()`（L406-413）；resize 事件里检测 maximized 边界（L400-420）。
- 设置卡即时改尺寸：`applySize` 若 maximized 先 unmaximize + 记 pendingCustomSize，再 setSize(逻辑)+center（L613-632）。
- 主题：`window.setTheme(Dark/Light)` + DWM `DwmSetWindowAttribute(hwnd, 20, v, 4)`（dwm-theme.ts 已核实，koffi 调 dwmapi）+ webview 背景色 + 窗口图标深浅；'system' 模式由 `WebViewThemeDetector` 跟随页面 `body[data-ds-dark-theme]`（MutationObserver + 100ms 轮询，theme-sync.ts 已核实）。
- 任务栏图标跟随 OS 主题（os-theme.ts 读 `SystemUsesLightTheme` 注册表）。
