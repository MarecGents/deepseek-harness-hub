# D-1 单实例行为决策

> 日期：2026-08-17 · 拍板权：用户 · SOP 前置：D1（M3 §4.2）

## 决策

**单实例二次启动 = 聚焦已有窗口**（推荐，默认值）。

- 使用 `tauri-plugin-single-instance`，`init` 回调内调 `win.show()` + `win.set_focus()`
- 不弹窗拒绝（rc.14 弹窗行为不迁移）
- 可选：向已有窗口 emit `"single-instance"` 事件（M4 扩展点）

## rc.14 行为对比

| 场景 | rc.14 | M3 |
|---|---|---|
| 窗口已运行，再次启动 | 弹窗"已在运行" | 聚焦已有窗口 |
