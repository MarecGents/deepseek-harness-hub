# 壳八项改进（grill-me 实测反馈）— DMAIC 记录

> 日期：2026-08-18 · 来源：用户实测后 /grill-me 提出的 8 项问题（设计决策经 grill 流程确认）
> 范围：Tauri 2.x 壳（标题栏/托盘菜单/声音/通知/工作区/控制台）

## Define（定义）— 8 项 CTQ 与用户决策

| # | CTQ | 用户决策（grill 确认） |
|---|---|---|
| 1 | 标题栏不挡右侧栏 | Q1=A：单 webview + 全页预留；高度 32→**42px**（+1/3，为未来标签页留空间） |
| 2 | 标题栏颜色 | Q2=B：**同向**匹配（浅色主题→浅色标题栏、深色→深色）、微差一档、跟随皮肤 token |
| 3 | 无控制台窗口 | 直接修：debug 也无黑窗 + 子进程不闪现 |
| 4 | 提示音/通知生效 | Q4：声音**永远触发**（不按 depth 过滤）；通知**非聚焦会话才弹**；toast 显示链路修复 |
| 5 | 托盘菜单颜色/位置 | Q2/Q5：颜色同向跟随皮肤；位置 = 窗口移到光标所在显示器托盘角 + 置顶，关闭还原（A） |
| 6 | 打开工作区有效 | Q6=C：打开**聚焦会话所在工作区**（rc.14 定位逻辑）+ 空值兜底 + 高速响应 |
| 7 | 右键不唤醒窗口/显示隐藏有效 | Q7：右键只弹菜单（隐藏时在托盘角弹出，关闭后回隐藏）；左键单/双可打开；第一项=显示/隐藏切换 |

## Measure / Analyze（测量与分析）— 取证结论（自研，含用户实测 dsh.log 证据）

1. **#4 声音根因（实证）**：`tauri sound "success" init failed: ReferenceError: Audio is not defined`（用户日志 02:44:14）——`tauri-shell.ts` 运行在 **Node 进程**，`new Audio` 不存在（D3 设计放错进程）。且 `/api/dsh-hub/sounds/*` **路由不存在**（浏览器 404）。修：Node→DSH_CMD→Rust→eval→浏览器 HTMLAudio；新增 sounds 静态路由；`--autoplay-policy=no-user-gesture-required`（WebView2 自动播放拦截）。
2. **#4 通知显示（源码取证）**：`tauri-plugin-notification` 用 config identifier `com.marecgents.dsh-hub` 作 AUMID（desktop.rs:27）；未打包应用必须注册 AUMID 才显示 toast。修：启动时注册 `HKCU\Software\Classes\AppUserModelId\com.marecgents.dsh-hub`（DisplayName/IconUri，幂等）。
3. **#2 颜色方向**：用户否定了上一轮的反色 chrome（浅→深栏）；确认**同向**（浅→浅、深→深）且微差一档。实现：`var(--dsw-alias-bg-layer-1)` + `label-secondary` + `border-l1`（token 由皮肤在 body 覆盖 → 自定义皮肤自动跟随）。
4. **#1 布局**：右侧栏 `.mg-rs-root` 是 body portal（`position:fixed; top:0; bottom:0`）→ 标题栏下移覆盖：壳注入 `#dsh-hub-right-sidebar-root .mg-rs-root{top:42px}`（ID 特异性胜，bottom:0 保底对齐）。
5. **#5 菜单定位（研究）**：Tauri 生态托盘菜单几乎全用原生菜单（光标处、不可样式化）；自绘 HTML 菜单受"只能在窗口内渲染"约束 → 用户批准的 A：窗口移到光标所在显示器工作区右下角 + 置顶 + 关闭还原（`cursor_position` + `monitor_from_point` + `work_area` API 确认存在）。
6. **#6 工作区（rc.14 取证）**：dev-v1 `currentWorkspace` = 当前会话→最近工作区（client 同步快照，快）；Tauri client 已有同逻辑；补：空路径兜底 $DSH_HOME；实测日志无 `open_workspace_path` 调用（链路/点击未达）→ 加日志与 E2E 断言。
7. **#3 控制台**：`main.rs` `cfg_attr(not(debug_assertions))` → debug 是控制台程序；子进程 cmd/dsh.cmd 也可能闪现。修：无条件 `windows_subsystem="windows"` + 子进程 `CREATE_NO_WINDOW`。
8. **#7 状态机**：右键菜单打开期间窗口被移到托盘角，需记录原位置/可见性，关闭后还原；「显示/隐藏主界面」切换项需 label 上下文（隐藏时显示"显示主界面"，可见时"隐藏主界面"）。
