  build-installer.mjs 新增 **host 依赖打包守卫**（外部 import 未覆盖 → 构建 FAIL）。

  曾残留 400MB。修复：`NSIS_HOOK_POSTUNINSTALL` 递归删 `_up_`/`icons`/`dsh-hub-win` +
  引导日志（末尾非递归 RMDir $INSTDIR）；best-effort 清理 profile 的 bundles 条目与
  悬空 junction（ReparsePoint 判定）——避免卸载后 `dsh web` CLI 崩溃。
