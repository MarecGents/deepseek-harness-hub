1. resources 增补插件本体（package.json/cordis.patch.yml/lib/assets/bin → `$INSTDIR\_up_`）。
2. node.rs junction 三级优先：`_up_`（安装包自带）→ dsh-hub-win npm 副本（兜底）→ dev 仓库根。

   安装后的 exe 永远误判 dev"缺陷，且排除旧事故的残缺 `_up_` 残留。
