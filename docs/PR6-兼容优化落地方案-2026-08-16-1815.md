## 二、步骤 0：背景图渲染层修复（v4 定稿）

### 锚点（v4 修正）
- ❌ ~~`#root > div`~~ —— 是 slot 出口 `div[data-slot="root"][style="display:contents"]`，无盒，注入不可见（F3 实证）。
- ✅ **主锚点：`#root div[style*="grid-template-columns"]`**（F4：活体实测唯一命中 frame，内联样式无 hash）。
- 备选（冒烟验证后可选）：`#root div[data-slot="root"] > div`（结构路径）。

### 注入规则（backgrounds.ts applyBackground 修改）
```css
#root div[style*="grid-template-columns"] {
  /* 双层背景：蒙层渐变 + 图片，两层都在 frame 自身背景 → 天然在内容之下、零层叠风险 */
  background-image:
    linear-gradient(rgba(0, 0, 0, 0.25), rgba(0, 0, 0, 0.25)),
    url("...") !important;
  background-size: cover, cover !important;
  background-position: center !important;
  background-repeat: no-repeat !important;
  background-attachment: fixed !important;
  /* background-color 不动：保留 var(--dsw-alias-bg-base)（皮肤 token）作 fallback */
}
```
- 蒙层透明度（0.25）为初值，按 boat.jpg 实测对比度微调（深色白字场景可到 0.35）。
- 仅 background !== 'none' 时注入；'none' 清空 textContent（与皮肤 default 一致，F9）。
- 作用域：frame 层覆盖**整窗**（两侧栏皮肤 fill 保留其上，图片在空隙/半透明处透出）。
- **决策点**：锚点漂移（升级回归冒烟项）→ 背景静默失效（可接受降级）或向 dsh 上游提议官方背景 slot（长期）。

### 验收标准（v4）
1. 选"远航" → 整窗 frame 层可见背景图（红色样张法验证：注入红色背景检查像素）。
2. **可读性**：深/浅两模式 + 皮肤叠加下置顶区/会话列表/聊天文字可读（双层背景蒙层兜底，elementFromPoint 验证内容可交互）。
3. 重启保持；高 DPI 尺寸正确（commit 2 回归）；frame 层无滚动容器，性能无碍。
4. **锚点回归冒烟**：dsh 升级后 `#root div[style*="grid-template-columns"]` 是否仍唯一命中 frame。
