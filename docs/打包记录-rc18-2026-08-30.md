## 本版内容（rc.17 基础上新增 2 项壳层体验修复）

### 图标跟随已移动的快捷方式（用户反馈）
- 现象：桌面快捷方式移到其他文件夹后，切换图标时该 lnk 与任务栏图标不变
- 根因：图标切换只改写「能找到的」lnk 的 IconLocation（指向随选择变化的 `{icon_id}.ico`）——移走的 lnk 永远停在旧 ico 上
- 修复：**固定锚点 `current.ico`**——所有 lnk/AUMID IconLocation 统一指向 exe 相邻 `icons\current.ico`；切换时把选中的 .ico 复制为 current.ico + SHCNE_UPDATEITEM/ASSOCCHANGED 通知 Explorer；已存在的 lnk 更新时一并改写 IconLocation 到锚点，从此任意位置永久跟随（踩坑 #97）
- 注意：旧机制创建且已移走的快捷方式需**重装本版**（NSIS 重建桌面 lnk）后进入新机制

### 启动 Splash 优化（用户反馈：风格割裂/加载不流畅）
- Splash 配色跟随当前皮肤与主题（`helpers/boot_theme.rs` 读 config + `skin-colors.json`（`scripts/export-skin-colors.mjs` 从 skins.ts 生成，15 套浅/深 bg-base+label-primary）→ 动态 initialization_script 注入 `__MG_BOOT_THEME`）；body/html 背景同步，导航间隙不再闪白
- 生命周期：占位页 Splash **常驻**（阶段文案「正在启动服务…」，30s 兜底）——不再 load 后淡出留数秒白窗；dsh 页「正在加载界面…」**轮询 #root 等 SPA 首绘再淡出**（8s 兜底）
- 性能说明：启动耗时大头是 node sidecar 到 dsh READY（约 8-15s），本版为感知层优化（风格一致/无白屏/阶段反馈）；真实缩短需后续立项（server 常驻复用）
