## 本版内容（相对 rc.11：插件工具输出契约 bug 修复）

### 根因（真实事故：两个论文会话「本轮运行失败 content.some is not a function」）
`dsh-permission-guard`（`permission_status` / `permission_reload`）与 `dsh-findings-ledger`（`findings_baseline` / `findings_record` / `findings_report`）的 `output.render` 返回**字符串**而非官方契约要求的 `ContentBlock[]` 数组 → 字符串写入会话日志的 tool-result block → 下一轮 LLM 请求重建时 provider adapter 的图片检查 `contentHasImage()` 递归进入该块对字符串调 `.some()` → 整轮 error（code UNKNOWN）。

### 修复
- 5 处 render 全部改为返回 `[{ type: 'text', text: … }]` 数组（permission-guard 2 + findings-ledger 3）
- 核查其余插件：`dsh-project-memory` 已是数组写法；`dsh-usage-stats` 无工具注册；host half（src/）无工具定义——无同类残留
- 防御方向（建议 dsh 官方）：`snapshotProjection` 对 render 结果做数组校验，隔离畸形插件而非毒化会话（已记入踩坑记录 #86）
