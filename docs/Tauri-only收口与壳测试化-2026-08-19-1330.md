## 关键发现与决策

- dsh 环境版本 0.1.0-rc.7；置顶会话 DOM 锚点（data-slot="sidebar.workspaces" + role="treeitem"）在 rc.7 仍存在。
- 主题「无变化」根因：皮肤色板解析键名（bg-layer-1 等）与消费方（pal.bg）不匹配 → 设置 undefined → 回退 token。修正归一化后验证 `shelltheme:dark bg=#0f1a30`（午夜蓝皮肤真实色板）。
- 多实例门禁在本机 WQL `-or` 报无效查询（0x80041017）→ 括号化 OR 规避。
- 本机无 VS/MSVC linker → MinGW gcc + GNU 工具链；mingw ld cdylib 导出序号溢出 → --exclude-all-symbols。
- 受限沙箱拦截脚本内 spawnSync 管道捕获（EPERM）→ build:client 等需 danger-full-access。
