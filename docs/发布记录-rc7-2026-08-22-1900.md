# 发布记录 — 0.0.2-rc.7（2026-08-22 19:00）

## 版本内容：安装→卸载→启动 全流程体验优化

- **卸载提速（用户核心诉求）**：可见卸载时长从 ~50s（rc.5/6 同步删 dsh-hub-win
  3.5 万文件）→ **实测 1.4-5s**。三段式：PREUNINSTALL 快速通道（小目录 RMDir /r，
  模板逐文件 Delete 变 no-op）+ POSTUNINSTALL 清扫/profile 清理 + **ExecShell
  （ShellExecute OS 级脱离）后台静默清理大批量文件**（无黑框、空目录 3s 重试）。
- **安装进度实时反馈**：bootstrap（1-3 分钟下载）改异步 + `DEP:` 进度行每 700ms
  镜像到安装器详情视图（ps1 `-LogPath` 落日志 + done/FAILED 哨兵，6min 上限），
  替换原 ExecWait 全程冻结。
- **启动体验**：AUMID 注册移后台线程（窗口首绘提前 ~0.5s；完成后补同步壳图标源
  修竞态）；占位页重写为与 dsh Splash 同视觉（同底色/48px 鲸鱼脉冲/同 spinner/
  动态省略号）；READY 导航前 `__mgFadeout` 220ms 淡出平滑衔接。

## 关键实测数据（沙箱 E2E，6 轮安装/卸载循环）

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 卸载可见时长 | ~50s（冻结式） | **1.4-5s**（后台静默清理随后完成，零残留） |
| 安装 bootstrap 期间 | 无任何反馈（冻结） | DEP 进度行实时滚动 |
| 哨兵收尾 | （本轮修复的回归：Write-Output 不落日志致 6min 超时） | 正常（Write-Dep 落日志） |

> 测量方法论教训（已录踩坑 #67 补充）：`Start-Process -Wait` 等待进程**及其全部
> 子进程**（job object），把后台异步清理计入"可见卸载"形成假象；卸载器主进程
> 本身 ~1s 即退（NSIS temp 副本机制），归因必须用钩子内时间戳标记。
